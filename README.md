# ParlaSchema

Swiss parliamentary PDFs to open data, with provenance for every field.

Hack Apertus submission for **Track 2A — OpenParlData**. The project root is
[`track_2a/`](track_2a/); see its [README](track_2a/README.md) for the
challenge, setup and how to run it.

```bash
cd track_2a
make run
```
