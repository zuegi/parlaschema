# ParlaSchema

Schema and provenance foundation for Swiss parliamentary open data, with a
synthetic offline block-classification demo and partial-negative feasibility
results. **The PDF-to-schema converter is not implemented; this is an
incomplete Track 2A submission.**

Hack Apertus submission for **Track 2A — OpenParlData**. The project root is
[`track_2a/`](track_2a/); see its [README](track_2a/README.md) for the
challenge, setup and how to run it.

```bash
cd track_2a
make run
```
